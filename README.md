# GitHub Pages Deployment Project

A responsive static website deployed using GitHub Pages.

## 🚀 Project Overview

This project demonstrates how to:

- Create a static website using HTML, CSS, and JavaScript
- Host a website for free using GitHub Pages
- Manage source code with Git and GitHub
- Deploy updates automatically through Git pushes

## 🛠 Technologies Used

- HTML5
- CSS3
- JavaScript
- Git
- GitHub Pages

## 🚀 Deployment Steps

1. Create project files
2. Initialize Git Repository
3. Push code to GitHub
4. Enable GitHub Pages
5. Select Main Branch
6. Save Settings
7. Access the generated website URL

## 🔄 Updating the Website

After making changes:

```bash
git add .
git commit -m "Updated website"
git push
```

GitHub Pages automatically redeploys the latest version.
